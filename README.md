# Fork of ReSpire
Continuation of the project that aims to implement training analysis and sensor support.

## App Versions
There are currently 2 active versions of the app:
- **`main` branch**: Stable version of the application (without the microphone breath monitor).
- **`1.9.x-mic-monitor` branch**: Version featuring the active microphone breath detection & monitoring pipeline.
  - The machine learning model used in the monitor version was developed and trained in [PCyganiuk/breathing-classification-v3](https://github.com/PCyganiuk/breathing-classification-v3).

## Technologies
